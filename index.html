Обновление пакетов системы и базовых утилит

Обновите индекс пакетов и установите базовые консольные утилиты, архиваторы (zip, unzip, p7zip-full) и инструменты определения MIME-типов файлов (file):

bash
apt update && apt upgrade -y
apt install -y curl wget nano zip unzip p7zip-full file ca-certificates lsb-release apt-transport-https
2

Установка Apache и перевод на порт 8080

Установим веб-сервер Apache2 и сразу переключим его с порта 80 на 8080:

bash
apt install -y apache2
sed -i 's/Listen 80/Listen 8080/g' /etc/apache2/ports.conf
sed -i 's/<VirtualHost \*:80>/<VirtualHost \*:8080>/g' /etc/apache2/sites-available/000-default.conf
echo "ServerName localhost" >> /etc/apache2/apache2.conf
3

Установка PHP-FPM и расширений

Устанавливаем PHP-FPM вместе с полным набором расширений для работы с БД, изображениями (gd, imagick, exif), архивами (zip), сетью (curl), многобайтовыми строками (mbstring) и XML/JSON:

bash
apt install -y php-fpm php-mysql php-sqlite3 php-cli php-curl php-gd php-imagick php-exif php-mbstring php-xml php-zip php-json php-intl php-bcmath php-fileinfo

Проверим установленную версию PHP:

bash
PHP_VER=$(php -r "echo PHP_MAJOR_VERSION.'.'.PHP_MINOR_VERSION;")
echo "Установленная версия PHP: $PHP_VER"
4

Подключение PHP-FPM к Apache (режим event MPM)

Переключаем Apache на быстрый многопоточный mpm_event, включаем proxy_fcgi, rewrite, headers и разрешаем работу .htaccess в /var/www/html:

bash
a2dismod php* mpm_prefork 2>/dev/null || true
a2enmod mpm_event proxy_fcgi setenvif rewrite headers

PHP_VER=$(php -r "echo PHP_MAJOR_VERSION.'.'.PHP_MINOR_VERSION;")
a2enconf php${PHP_VER}-fpm

cat << 'EOF' > /etc/apache2/conf-available/override-html.conf
<Directory /var/www/html>
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>
EOF
a2enconf override-html
5

Настройка лимитов PHP-FPM (загрузка крупных файлов и видео)

Для файлообменника, загрузки видео, архивов и крупных APK увеличим лимиты в php.ini до 1024 МБ (1 ГБ) и время выполнения скриптов до 600 секунд (полезно при конвертации видео через FFmpeg):

bash
PHP_VER=$(php -r "echo PHP_MAJOR_VERSION.'.'.PHP_MINOR_VERSION;")
PHP_INI="/etc/php/${PHP_VER}/fpm/php.ini"

sed -i 's/^upload_max_filesize = .*/upload_max_filesize = 1024M/' "$PHP_INI"
sed -i 's/^post_max_size = .*/post_max_size = 1024M/' "$PHP_INI"
sed -i 's/^memory_limit = .*/memory_limit = 512M/' "$PHP_INI"
sed -i 's/^max_execution_time = .*/max_execution_time = 600/' "$PHP_INI"
sed -i 's/^max_input_time = .*/max_input_time = 600/' "$PHP_INI"
sed -i 's/^max_file_uploads = .*/max_file_uploads = 50/' "$PHP_INI"
Важно: Убедитесь, что в disable_functions в php.ini не заблокированы функции exec и shell_exec (в Debian по умолчанию они разрешены), так как они нужны PHP для вызова ffmpeg и aapt.

Установка и защита MariaDB

FFmpeg и инструменты для работы с видео и аудио

FFmpeg (вместе с ffprobe) необходим для генерации видео-превью (кадров-миниатюр), конвертации видео в MP4/WebM, сжатия, извлечения аудиодорожек и получения метаданных (длительность, разрешение, битрейт, кодек).

bash
apt install -y ffmpeg mediainfo
  • ffmpeg — конвертация, нарезка, создание превью (thumbnail) из любого видеофайла.
  • ffprobe (входит в пакет ffmpeg) — быстрое получение JSON с точным разрешением, длительностью и FPS видео.
  • mediainfo — подробный технический паспорт любых медиафайлов (видео, аудио, контейнеры).

Пример вызова из PHP (создание превью на 2-й секунде видео):

php
$cmd = "ffmpeg -ss 00:00:02 -i " . escapeshellarg($videoPath) . " -vframes 1 -q:v 3 " . escapeshellarg($thumbPath) . " -y 2>&1";
exec($cmd, $output, $returnCode);

Модули для работы с изображениями и графикой

Помимо PHP-расширений php-gd, php-imagick и php-exif (установленных на Шаге 3), установим системные утилиты и библиотеки форматов (WebP, HEIC/AVIF, оптимизаторы PNG/JPEG и векторный SVG):

bash
apt install -y imagemagick webp libheif-examples libavif-bin librsvg2-bin jpegoptim optipng pngquant exiftool
  • imagemagick + php-imagick — ресайз, обрезка, водяные знаки, конвертация PSD/SVG/TIFF/PDF в PNG/WebP.
  • webp (cwebp, dwebp) — сжатие загружаемых фото в лёгкий формат WebP.
  • libheif-examples (heif-convert) — конвертация фото с iPhone (.heic) в стандартный JPG/PNG.
  • librsvg2-bin (rsvg-convert) — качественный рендеринг векторных иконок SVG в растровый PNG.
  • jpegoptim / optipng / pngquant — сжатие картинок без видимой потери качества.
  • exiftool + php-exif — чтение и удаление EXIF-метаданных (координаты GPS, модель камеры, ориентация поворота фото).

Модули для работы с документами (PDF, Office, Текст)

Для генерации миниатюр первой страницы PDF, извлечения текста для поиска, конвертации офисных документов (.docx, .xlsx, .pptx) и распознавания текста со сканов:

bash
apt install -y poppler-utils ghostscript qpdf pandoc unoconv tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng
  • poppler-utils (pdftoppm, pdftotext, pdfinfo) — мгновенное создание PNG-обложки 1-й страницы PDF, подсчёт страниц и извлечение текста.
  • ghostscript + qpdf — сжатие тяжёлых PDF-файлов, объединение и разделение страниц.
  • pandoc — конвертация документов между Markdown, DOCX, HTML, EPUB, RTF.
  • tesseract-ocr (-rus, -eng) — оптическое распознавание текста (OCR) с фотографий документов и скриншотов.
Если нужна полная конвертация DOC/DOCX/XLSX в PDF на сервере: дополнительно можно установить apt install -y libreoffice-nogui (занимает ~350–450 МБ на диске, позволяет конвертировать любые файлы Office в PDF командой libreoffice --headless --convert-to pdf file.docx).

Инструменты для извлечения данных и иконок из APK

Для серверного анализа Android-пакетов (.apk) — чтения AndroidManifest.xml, получения названия приложения, имени пакета (package name), versionName, versionCode, разрешений (uses-permission), проверки цифровой подписи и извлечения иконки приложения:

bash
apt install -y aapt apksigner zipalign dexdump apktool default-jre-headless
  • aapt (Android Asset Packaging Tool) — самый быстрый консольный инструмент (написан на C++, не требует запуска тяжёлой JVM). Мгновенно извлекает всю метаинформацию из APK и путь к иконке.
  • apksigner — проверка подписи APK (apksigner verify --verbose app.apk) и данных о сертификате разработчика.
  • apktool — полная распаковка бинарного AndroidManifest.xml и ресурсов (res/) в читаемый вид (использует default-jre-headless).
  • unzip + php-zip (ZipArchive) — так как APK это обычный ZIP-архив, зная путь к иконке из aapt, PHP может достать PNG/WebP иконку напрямую за миллисекунды!

Пример получения всех данных и иконки из APK в терминале:

bash
# 1. Получить package name, версию, название приложения, SDK и путь к иконке:
aapt dump badging /var/www/html/app.apk

# 2. Получить список всех запрошенных приложением разрешений:
aapt dump permissions /var/www/html/app.apk

# 3. Извлечь файл иконки (например, res/mipmap-xxxhdpi-v4/ic_launcher.png) из APK:
unzip -p /var/www/html/app.apk "res/mipmap-xxxhdpi-v4/ic_launcher.png" > /var/www/html/icon.png

Права доступа на стандартный каталог /var/www/html

Назначим владельца www-data и правильные права доступа на директорию веб-сервера:

bash
chown -R www-data:www-data /var/www/html
find /var/www/html -type d -exec chmod 755 {} \;
find /var/www/html -type f -exec chmod 644 {} \;

Как изменить рабочую директорию сайта (DocumentRoot)

Если вы хотите перенести корень сайта из стандартного /var/www/html в другую папку (например, во внешнюю или общую папку Android/Termux /sdcard/WWW или /srv/site), нужно обновить путь в трёх местах: в виртуальном хосте Apache, в глобальном apache2.conf и выдать права доступа.

Вариант А: Автоматическая замена пути через скрипт (подставьте свой путь в NEW_DIR)

bash
# Укажите нужный путь к вашей папке сайта:
NEW_DIR="/srv/my_site"

# 1. Создаём папку, если её ещё нет
mkdir -p "$NEW_DIR"

# 2. Меняем DocumentRoot в конфигурации виртуального хоста 000-default.conf
sed -i "s|DocumentRoot /var/www/html|DocumentRoot ${NEW_DIR}|g" /etc/apache2/sites-available/000-default.conf

# 3. Разрешаем Apache доступ к новой директории и работу .htaccess
cat << EOF > /etc/apache2/conf-available/override-html.conf
<Directory ${NEW_DIR}>
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>
EOF

# 4. Назначаем владельца www-data и перезапускаем Apache
chown -R www-data:www-data "$NEW_DIR"
chmod -R 755 "$NEW_DIR"
apachectl configtest && service apache2 restart

Вариант Б: Ручное редактирование (если нужно поправить вручную)

  1. Откройте конфиг сайта: nano /etc/apache2/sites-available/000-default.conf и измените строку DocumentRoot /var/www/html на ваш путь (например, DocumentRoot /sdcard/SITE).
  2. Откройте общий конфиг Apache: nano /etc/apache2/apache2.conf (или /etc/apache2/conf-available/override-html.conf), найдите блок <Directory /var/www/> и добавьте или исправьте блок для вашей новой папки с параметром Require all granted (иначе Apache выдаст ошибку 403 Forbidden).
  3. Проверьте синтаксис apachectl configtest и перезапустите: service apache2 restart.
Особенность папок Android (/sdcard/...) в Termux Debian: На файловой системе Android (sdcardfs / FUSE) команда chown не меняет владельца, а доступ зависит от группы Android-хранилища (aid_everybody / 9997). Чтобы Apache (www-data) мог читать и записывать файлы в /sdcard/SITE, добавьте пользователя www-data в системную группу с GID 9997 (или sdcard_rw / 1015):
groupadd -g 9997 sdcard_all 2>/dev/null || true && usermod -aG 9997 www-data

Автоматизация запуска и остановки сервера одной командой

Создадим исполняемые системные команды start, stop и restart в /usr/local/bin/, чтобы запускать весь стек одной короткой командой из любой директории терминала.

14.1. Команда start (запуск MariaDB, PHP-FPM и Apache на порту 8080):

bash
cat << 'EOF' > /usr/local/bin/start
#!/bin/bash
echo "Запуск APACHE, MYSQL и PHP-сервера на порту 8080..."
service mariadb start && service php8.4-fpm start && service apache2 start
EOF
chmod +x /usr/local/bin/start

После выполнения этого блока достаточно просто написать start в терминале из любой папки — сервер сразу запустится. (Если у вас в Debian установилась другая версия PHP, например 8.2, просто замените php8.4-fpm на вашу версию).

14.2. Дополнительно: команды stop и restart для полного контроля:

bash
cat << 'EOF' > /usr/local/bin/stop
#!/bin/bash
echo "Остановка APACHE, PHP-FPM и MariaDB..."
PHP_VER=$(php -r "echo PHP_MAJOR_VERSION.'.'.PHP_MINOR_VERSION;")
service apache2 stop
service php${PHP_VER}-fpm stop
service mariadb stop
echo "Все службы остановлены."
EOF
chmod +x /usr/local/bin/stop

cat << 'EOF' > /usr/local/bin/restart
#!/bin/bash
echo "Перезапуск APACHE, PHP-FPM и MariaDB..."
PHP_VER=$(php -r "echo PHP_MAJOR_VERSION.'.'.PHP_MINOR_VERSION;")
service mariadb restart && service php${PHP_VER}-fpm restart && service apache2 restart
echo "Сервер перезапущен на порту 8080!"
EOF
chmod +x /usr/local/bin/restart

Теперь в терминале Debian достаточно ввести start для запуска, restart для перезагрузки или stop для остановки.

Запуск Cloudflare Tunnel в Termux

Да, ваш синтаксис для запуска именованного туннеля tablet на локальный порт 8080 полностью правильный! Разберём нюансы запуска в обычном Termux и в Termux Debian:

15.1. Запуск в обычном Termux (основная оболочка Android):

Если пакет cloudflared установлен в самом Termux (pkg install cloudflared) и авторизован (cloudflared tunnel login), запускайте в отдельной вкладке/сессии Termux:

bash
cloudflared tunnel run --url http://127.0.0.1:8080 tablet

15.2. Запуск в фоновом режиме (чтобы не занимать окно терминала):

Чтобы туннель работал в фоне и писал лог в файл, используйте nohup или tmux / screen:

bash
# Запуск в фоне с записью лога:
nohup cloudflared tunnel run --url http://127.0.0.1:8080 tablet > ~/cloudflared.log 2>&1 &

# Посмотреть статус / лог работы туннеля:
tail -f ~/cloudflared.log

# Остановить фоновый туннель:
pkill cloudflared

15.3. Полезные флаги для мобильного интернета / Wi-Fi (QUIC vs HTTP2):

На мобильных сетях или Android некоторые провайдеры режут UDP-трафик (протокол quic, который cloudflared использует по умолчанию). Если туннель долго подключается или обрывается, добавьте флаг --protocol http2:

bash
cloudflared tunnel --protocol http2 run --url http://127.0.0.1:8080 tablet
Важно при работе внутри Termux Debian (proot-distro):
1. Сеть между Termux и Termux Debian общая (127.0.0.1 единый), поэтому cloudflared можно запускать как из самого Termux, так и из Debian.
2. Если запускаете внутри proot-distro (Debian), иногда cloudflared ругается на отсутствие доступа к /proc/net/route при автоопределении IP. В этом случае надёжнее запускать cloudflared из родного Termux, а в Termux включить Acquire wakelock в шторке уведомлений, чтобы Android не усыплял процессор при выключенном экране!

Комплексная проверка всех модулей и утилит

Создадим проверочный скрипт check_server.php в корне сайта (в примере — /var/www/html/check_server.php), который протестирует PHP-FPM, MariaDB, GD, Imagick, Zip, FFmpeg, AAPT, Poppler и ImageMagick:

bash
cat << 'EOF' > /var/www/html/check_server.php
<?php
header('Content-Type: text/html; charset=utf-8');
echo "<style>body{font-family:sans-serif;background:#1a1d24;color:#e2e8f0;padding:20px;} .ok{color:#22c55e;font-weight:bold;} .err{color:#ef4444;font-weight:bold;} table{border-collapse:collapse;width:100%;max-width:750px;} td,th{border:1px solid #334155;padding:8px 12px;text-align:left;}</style>";
echo "<h2>Диагностика сервера (Порт " . $_SERVER['SERVER_PORT'] . ")</h2>";
echo "<p>DocumentRoot: <b>" . $_SERVER['DOCUMENT_ROOT'] . "</b><br>";
echo "PHP SAPI: <span class='ok'>" . php_sapi_name() . "</span> | Версия PHP: <span class='ok'>" . phpversion() . "</span></p>";

$exts = ['pdo_mysql', 'gd', 'imagick', 'exif', 'zip', 'curl', 'mbstring', 'xml', 'fileinfo'];
echo "<h3>PHP Расширения</h3><table><tr><th>Модуль</th><th>Статус</th></tr>";
foreach ($exts as $ext) {
    $st = extension_loaded($ext) ? "<span class='ok'>Установлен</span>" : "<span class='err'>Отсутствует</span>";
    echo "<tr><td>$ext</td><td>$st</td></tr>";
}
echo "</table>";

$bins = [
    'ffmpeg' => 'ffmpeg -version | head -n 1',
    'ffprobe' => 'ffprobe -version | head -n 1',
    'aapt' => 'aapt version',
    'apksigner' => 'apksigner --version',
    'apktool' => 'apktool --version',
    'convert (ImageMagick)' => 'convert -version | head -n 1',
    'cwebp (WebP)' => 'cwebp -version',
    'pdftoppm (PDF)' => 'pdftoppm -v 2>&1 | head -n 1',
    'exiftool' => 'exiftool -ver'
];
echo "<h3>Системные консольные утилиты</h3><table><tr><th>Утилита</th><th>Версия / Статус</th></tr>";
foreach ($bins as $name => $cmd) {
    $out = trim(shell_exec($cmd . " 2>&1"));
    $st = $out ? "<span class='ok'>" . htmlspecialchars($out) . "</span>" : "<span class='err'>Не найдено</span>";
    echo "<tr><td>$name</td><td>$st</td></tr>";
}
echo "</table>";
EOF
chown www-data:www-data /var/www/html/check_server.php

Откройте в браузере http://127.0.0.1:8080/check_server.php. После проверки удалите файл (rm /var/www/html/check_server.php).
